# TheEntryExit

TheEntryExit is a sci-fi trading command center for calculators, simulators, prop-firm offers and trading resources.

## Included
- Responsive sci-fi homepage
- Dark deep-space theme
- Light sunrise/day theme
- Animated market ribbon
- Tool navigation and dedicated tool views
- Monte Carlo simulator
- Breakeven win-rate calculator
- Max loss-streak simulator with 50–500 trade sequences
- Static and intraday trailing drawdown simulator
- Consistency calculator
- Profit split calculator
- Responsive mobile layout
- Reduced-motion support

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Prop-firm offers are intentionally not fabricated. Add verified firm data before publishing discounts or codes.
