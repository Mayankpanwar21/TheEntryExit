# TheEntryExit

TheEntryExit is a sci-fi trading command center for simulators, calculators, prop-firm offers and trading resources.

## Current foundation
- React + Vite
- Space-inspired dark theme
- Sunrise/day concept reserved for light mode
- Responsive navigation
- Tools and prop-firm homepage sections
- Reusable tool and dropdown components
- Ready for dedicated simulator pages

## Planned tools
- Monte Carlo Simulator
- Breakeven Win Rate Simulator
- Max Loss Streak Simulator
- Daily Loss / Drawdown Simulator
- Consistency Rule Calculator
- Profit Split Calculator

## Run locally
```bash
npm install
npm run dev
```
